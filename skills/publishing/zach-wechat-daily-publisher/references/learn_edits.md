# Learn Edits

This is inspired by WeWrite's edit-learning loop, but kept small.

When Zach provides a revised article:

1. Compare the original local draft with the revised text.
2. Extract only durable writing preferences, not one-off fixes.
3. Add concise rules to the target repo's local memory or a future
   `playbook.md`.

Good learned rules are imperative:

- "Use shorter section titles that sound spoken."
- "Cut repeated `不是 X，而是 Y` constructions."
- "Prefer family-action endings over abstract summaries."

Do not turn every edit into a rule. Wait for repeated patterns before making a
hard constraint.
